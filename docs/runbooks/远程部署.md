# 远程部署与启动 ComfyUI

本文负责把本机维护的 `comfy-shell-v3` 部署到远端 GPU 机器，并启动 ComfyUI `v0.36.0`，最后通过本机浏览器访问 ComfyUI Web。

## 工作模型

```text
本机 macOS
  -> 修改 comfy-shell-v3 源码
  -> git push
  -> 建立 SSH tunnel
  -> 浏览器打开 ComfyUI

远端 GPU 机器
  -> /data/wangqiao/comfy-shell-v3             项目源码
  -> /data/wangqiao/comfy-shell-v3-workspace   ComfyUI versions/current/models/logs/run
  -> 启动 Comfy shell API 和 ComfyUI
```

日常入口优先使用 `./scripts/run.sh`。`dev.sh`、`remote.sh`、`comfyctl` 是底层原子入口，主要用于排障。

## 1. 本机提交代码

在本机 macOS：

```bash
cd /Users/admin/Code/comfy-shell-v3

./scripts/verify.sh check
git add .
git commit -m "update comfy shell"
git push
```

## 2. 远端准备代码和配置

在远端 GPU 机器：

```bash
ssh wangqiao@47.94.108.140

cd /data/wangqiao/comfy-shell-v3
git pull --ff-only
uv sync --frozen
```

确认服务器自己的 `.env` 至少包含：

```dotenv
RUNTIME__APP_ENV=dev
COMFY__WORKSPACE_DIR=/data/wangqiao/comfy-shell-v3-workspace
COMFY__REPO_URL=https://github.com/Comfy-Org/ComfyUI.git
API_HOST=127.0.0.1
API_PORT=8700
COMFY__HOST=127.0.0.1
COMFY__PORT=8188
```

远端 `.env` 不应该包含 `REMOTE__*`。`REMOTE__*` 只属于本机侧 SSH 编排配置。

`dev/.env` 是本机维护的远端配置备份和参考；部署时不要无条件覆盖服务器 `.env`。

## 3. 初始化 workspace

在远端项目目录：

```bash
./scripts/run.sh check dev
./scripts/run.sh init dev
```

这会创建：

```text
/data/wangqiao/comfy-shell-v3-workspace/
  sources/
  versions/
  models/
  logs/
  run/
  state.json
```

## 4. 拉取 ComfyUI v0.36.0 并设为 current

日常推荐用 `run.sh switch` 一步完成：

```bash
./scripts/run.sh switch v0.36.0
```

它会按顺序执行：

```text
fetch v0.36.0
  -> use resolved version
  -> models link
  -> versions current
```

也可以手动执行：

```bash
VERSION_NAME="$(
  ./scripts/run.sh versions fetch v0.36.0 \
    | uv run python -c 'import json,sys; print(json.load(sys.stdin)["name"])'
)"

./scripts/run.sh versions use "$VERSION_NAME"
./scripts/run.sh models link
./scripts/run.sh versions current
```

或完全手动执行：

```bash
./scripts/run.sh versions fetch v0.36.0
./scripts/run.sh versions list
```

看到类似下面的版本名后，再替换执行：

```text
ComfyUI-v0.36.0-a1b2c3d
```

```bash
./scripts/run.sh versions use ComfyUI-v0.36.0-a1b2c3d
./scripts/run.sh models link
```

## 5. 启动远端服务

在远端项目目录：

```bash
./scripts/run.sh up dev
./scripts/run.sh status dev
```

启动后应有两个本地监听服务：

```text
Comfy shell API  -> 127.0.0.1:8700
ComfyUI Web      -> 127.0.0.1:8188
```

查看 ComfyUI 日志：

```bash
./scripts/run.sh logs comfyui
```

## 6. 本机建立 SSH tunnel

在本机 macOS 新开一个终端：

```bash
ssh -N \
  -L 8700:127.0.0.1:8700 \
  -L 8188:127.0.0.1:8188 \
  wangqiao@47.94.108.140
```

保持这个终端不要关闭。

## 7. 本机浏览器打开

ComfyUI Web：

```text
http://127.0.0.1:8188
```

Comfy shell API 文档：

```text
http://127.0.0.1:8700/docs
```

## 常见排障

### 8188 已经被占用

先在远端查看：

```bash
lsof -i:8188
```

如果看到旧服务，例如来自 `/data/wangqiao/comfy-shell/ComfyUI`，说明当前端口已经被旧 ComfyUI 占用。此时二选一：

```text
停止旧服务
  -> 再用 comfy-shell-v3 管理 8188

或修改远端 .env
  -> COMFY__PORT=8189
  -> 本机 tunnel 改成 -L 8189:127.0.0.1:8189
```

不要用 `comfy-shell-v3` 的 `down dev` 去停不属于它启动的旧进程。

### 查看当前版本

```bash
./scripts/run.sh versions current
./scripts/run.sh versions list
```

### 停止服务

```bash
./scripts/run.sh down dev
```

### 重新部署

常规路径仍然是本机提交、远端拉取：

```bash
cd /data/wangqiao/comfy-shell-v3
git pull --ff-only
uv sync --frozen
./scripts/run.sh restart dev
```
