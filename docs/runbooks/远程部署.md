# 远程部署与启动 ComfyUI

本文负责把本机维护的 `comfy-shell-v3` 部署到远端 GPU 机器，接管一个已经验证可运行的 ComfyUI runtime，并通过本机浏览器访问 ComfyUI Web。

## 工作模型

```text
本机 macOS
  -> 修改 comfy-shell-v3 源码
  -> git push
  -> 建立 SSH tunnel
  -> 浏览器打开 ComfyUI

远端 GPU 机器
  -> /data/wangqiao/comfy-shell-v3             项目源码
  -> /data/wangqiao/comfy-shell-v3-workspace   runtimes/current/models/logs/run
  -> 启动 Comfy shell API 和 ComfyUI
```

`comfy-shell-v3` 不负责从零安装 ComfyUI，不自动解决 Torch、CUDA、driver 或 custom nodes 兼容问题。它负责复制已验证 runtime、维护软链接、启动服务、查看状态和日志。

日常入口优先使用 `./scripts/run.sh`。`dev.sh`、`remote.sh`、`comfyctl` 是底层原子入口，主要用于排障。

## 1. 本机提交代码

在本机 macOS：

```bash
cd /Users/admin/Code/comfy-shell-v3

./scripts/verify.sh check
git add .
git commit -m "update comfy shell"
git push
```

## 2. 远端准备代码和配置

在远端 GPU 机器：

```bash
ssh wangqiao@47.94.108.140

cd /data/wangqiao/comfy-shell-v3
git pull --ff-only
uv sync --frozen
```

确认服务器自己的 `.env` 至少包含：

```dotenv
RUNTIME__APP_ENV=dev
COMFY__WORKSPACE_DIR=/data/wangqiao/comfy-shell-v3-workspace
API_HOST=127.0.0.1
API_PORT=8700
COMFY__HOST=127.0.0.1
COMFY__PORT=8188
```

远端 `.env` 不应该包含 `REMOTE__*`。`REMOTE__*` 只属于本机侧 SSH 编排配置。

`dev/.env` 是本机维护的远端配置备份和参考；部署时不要无条件覆盖服务器 `.env`。

## 3. 初始化 workspace

在远端项目目录：

```bash
./scripts/run.sh check dev
./scripts/run.sh init dev
```

这会创建：

```text
/data/wangqiao/comfy-shell-v3-workspace/
  runtimes/
  versions/
  envs/
  models/
  logs/
  run/
  state.json
```

`versions/` 和 `envs/` 是低层归档/排障目录，不是日常安装入口。

## 4. 导入已验证 ComfyUI runtime

当前远端已验证候选：

```text
ComfyUI 源码: /data/wangqiao/comfy-shell/ComfyUI
Python venv: /data/wangqiao/comfy-shell/.venv
```

可先用临时端口验证它还能启动：

```bash
cd /data/wangqiao/comfy-shell/ComfyUI
/data/wangqiao/comfy-shell/.venv/bin/python main.py --listen 127.0.0.1 --port 8199
```

确认可访问后停止该临时进程，再在 `comfy-shell-v3` 项目目录导入：

```bash
cd /data/wangqiao/comfy-shell-v3

./scripts/run.sh import-runtime comfyui-0.27.0-known-good \
  --comfy-dir /data/wangqiao/comfy-shell/ComfyUI \
  --venv-dir /data/wangqiao/comfy-shell/.venv
```

导入后的规范位置：

```text
/data/wangqiao/comfy-shell-v3-workspace/
  runtimes/
    comfyui-0.27.0-known-good/
      ComfyUI/
      .venv/
      .comfy-shell-runtime.json
  runtimes.json
```

## 5. 切换 current

```bash
./scripts/run.sh switch comfyui-0.27.0-known-good
./scripts/run.sh runtimes current
```

这会更新：

```text
current     -> runtimes/comfyui-0.27.0-known-good/ComfyUI
current-env -> runtimes/comfyui-0.27.0-known-good/.venv
current/models -> workspace/models
```

## 6. 启动远端服务

在远端项目目录：

```bash
./scripts/run.sh up dev
./scripts/run.sh status dev
```

启动后应有两个本地监听服务：

```text
Comfy shell API  -> 127.0.0.1:8700
ComfyUI Web      -> 127.0.0.1:8188
```

查看 ComfyUI 日志：

```bash
./scripts/run.sh logs comfyui
```

## 7. 本机检查端口映射

在本机 macOS：

```bash
cd /Users/admin/Code/comfy-shell-v3
./scripts/run.sh remote status
```

输出里应先看到 Port Map：

```text
api      tunnel  local 127.0.0.1:8700 -> 47.94.108.140:127.0.0.1:8700
comfyui  tunnel  local 127.0.0.1:8188 -> 47.94.108.140:127.0.0.1:8188
```

第一版要求本机和远端使用同名端口：

```dotenv
API_PORT=8700
COMFY__PORT=8188
```

如果本机端口已被占用，先停掉占用进程；不要临时改浏览器地址或手写 `ssh -L` 绕过配置。

## 8. 本机建立 SSH tunnel

在本机 macOS 新开一个终端：

```bash
cd /Users/admin/Code/comfy-shell-v3
./scripts/run.sh remote tunnel
```

`remote tunnel` 会在启动前检查：

```text
本机 8700 / 8188 是否空闲
远端 8700 / 8188 是否正在监听
```

保持这个终端不要关闭。关闭后本机浏览器就无法通过 tunnel 访问远端服务。

## 9. 本机浏览器打开

ComfyUI Web：

```text
http://127.0.0.1:8188
```

Comfy shell API 文档：

```text
http://127.0.0.1:8700/docs
```

## 常见排障

### 8188 已经被占用

先在远端查看：

```bash
lsof -i:8188
```

如果看到旧服务，例如来自 `/data/wangqiao/comfy-shell/ComfyUI`，说明当前端口已经被旧 ComfyUI 占用。此时二选一：

```text
停止旧服务
  -> 再用 comfy-shell-v3 管理 8188

或修改远端 .env
  -> COMFY__PORT=8189
  -> 本机 .env 同步 COMFY__PORT=8189
  -> 继续使用 ./scripts/run.sh remote tunnel
```

不要用 `comfy-shell-v3` 的 `down dev` 去停不属于它启动的旧进程。

### 本机 tunnel 端口被占用

本机执行：

```bash
lsof -i:8188
lsof -i:8700
```

如果看到旧的 `ssh -L` 或其他本机服务占用端口，先停掉它，再重新执行：

```bash
./scripts/run.sh remote tunnel
```

第一版不建议随手改成本机 `18188` 这类临时端口，因为这会让文档、浏览器地址和远端服务端口漂移。

### 查看当前 runtime

```bash
./scripts/run.sh runtimes current
./scripts/run.sh runtimes list
```

### 停止服务

```bash
./scripts/run.sh down dev
```

### 重新部署

常规路径仍然是本机提交、远端拉取：

```bash
cd /data/wangqiao/comfy-shell-v3
git pull --ff-only
uv sync --frozen
./scripts/run.sh restart dev
```
